First, separate three different questions

1. Current posture

What do the six joints say in this sample? classify() returns CLOSED, OPEN or None.

2. Pending posture

Which candidate is being timed? A matching run of processed observations must span at least 60 ms.

3. Stable phase

What does the counter remember? self.state is UNKNOWN, CLOSED or OPEN. The phase changes only after confirmation, or a reset.

UNKNOWN means “the cycle has not been armed from a confirmed CLOSED pose.” A person can look OPEN in the current sample while the stable phase remains UNKNOWN. Confirming OPEN alone cannot start a cycle.

A repetition is a remembered sequence: confirmed CLOSED → confirmed OPEN → confirmed CLOSED. Only the final OPEN → CLOSED transition adds one.

An intermediate pose does not automatically mean UNKNOWN. Valid joints that satisfy neither complete posture return None: keep the stable phase and cancel the pending timer. Invalid required joints or invalid body scale also return None, but first reset the phase to UNKNOWN. These two cases have different effects.

The actual measurements and thresholds

The input is pose[joint] = [x, y, confidence]. x is a fraction of the original image width; y is a fraction of the original image height. Smaller y is higher in the picture. The app uses shoulders (5, 6), wrists (9, 10), and ankles (15, 16). Left and right are the person's anatomical sides.

width = abs(left_shoulder.x - right_shoulder.x) span = average(ankle.y) - average(shoulder.y) feet = abs(left_ankle.x - right_ankle.x) / width left = left_wrist.y - left_shoulder.y right = right_wrist.y - right_shoulder.y margin = 0.10 * span

height in the actual code is the vertical shoulder-to-ankle span above. It is a 2D image measurement. width is measured from every current pose; there is no fixed shoulder width of 0.2.

All conditions in one posture's column must pass in the same sample.
TestCLOSED: hands down, feet narrowOPEN: hands up, feet wide
Left wristleft > +marginleft < -margin
Right wristright > +marginright < -margin
Feetfeet ≤ 1.0feet ≥ 1.4

Each of the six joints needs finite x, y and confidence, with confidence ≥ 0.5. Body scale also needs width ≥ 0.01 and span > 0. Wrist boundaries are strict; foot boundaries are inclusive.

See one easy numerical example

Example shoulders: x = 0.4 and 0.6; both y = 0.4. Example ankles: both y = 0.9. This gives width 0.2, span 0.5 and margin 0.05. These are synthetic example measurements, not fixed settings.

  • Hands up: both wrist y values must be below 0.35 numerically, meaning physically above the limit in the image.
  • Hands down: both wrist y values must be greater than 0.45.
  • Feet open: horizontal ankle separation must be at least 0.28 (= 1.4 × 0.2).
  • Feet closed: separation must be at most 0.20 (= 1.0 × 0.2).
  • Hands up with feet ratio 1.2 satisfies neither complete posture. The stable phase is preserved; the candidate timer is canceled.

Production poses are float32; values extremely close to a boundary can be affected by rounding.

        ratio = abs(float(pose[LEFT_ANKLE, 0] - pose[RIGHT_ANKLE, 0])) / width
        # L81: Left wrist y minus its own shoulder y. Negative means above the shoulder because image y increases downward.
        left = float(pose[LEFT_WRIST, 1] - pose[LEFT_SHOULDER, 1])
        # L82: Compute the same signed vertical offset on the right side.
        right = float(pose[RIGHT_WRIST, 1] - pose[RIGHT_SHOULDER, 1])
        # L83: Set the hand clearance to 0.10 times height by default. It is recomputed from the current pose.
        margin = cfg.wrist_margin * height
        # L84: AND requires all three CLOSED gates together: both wrists below their shoulder margins and feet ratio <= 1.0.
        if left > margin and right > margin and ratio <= cfg.closed_ankle_ratio:
            # L85: Return the current posture CLOSED. This return alone does not confirm phase or add a rep.
            return ExerciseState.CLOSED
        # L86: AND requires all three OPEN gates: both wrists above the negative margins and feet ratio >= 1.4.
        if left < -margin and right < -margin and ratio >= cfg.open_ankle_ratio:
            # L87: Return the current posture OPEN. Timing and cycle history still have to pass in update().
            return ExerciseState.OPEN
        # L88: Valid intermediate pose: return None WITHOUT resetting. update() clears pending but preserves the stable phase.
        return None  # hysteresis dead band: keep stable phase, cancel confirmation

    # L90: Process one PosePacket and return the counter total (int). This combines safety, timing and phase history.
    def update(self, packet: PosePacket) -> int:
        # L91: Ignore any frame index that is not newer than the last one already processed.
        if packet.frame_index <= self.last_frame:
            # L92: Return immediately; a duplicate cannot start a timer, reset a phase or add a repetition.
            return self.rep_count
        # L93: Start building the continuity-change flag.
        changed = (
            # L94: A different generation means selection/loss/recovery changed continuity, even with the same track ID.
            packet.generation != self.generation
            # L95: OR a different selected track ID also counts as a continuity break.
            or packet.selected_track_id != self.track_id
        # L96: Finish the Boolean flag: changed is true if either comparison is true.
        )
        # L97: If continuity changed, handle it before considering a timestamp-gap reset.
        if changed:
            # L98: Forget the old partial cycle and pending candidate.
            self.reset_phase()
            # L99: Reseed the worker total from the main process's accepted count. Unaccepted worker progress may be discarded.
            self.rep_count = packet.accepted_reps
        # L100: Only when continuity did not change, consider the next timestamp-gap condition (elif = otherwise if).
        elif (
            # L101: A gap check needs an existing previous packet timestamp.
            self.last_timestamp is not None
            # L102: Start negating the WHOLE chained range comparison across the next two lines, not just the literal zero.
            and not 0
            # L103: The current-minus-previous packet timestamp must be nonnegative.
            <= packet.timestamp - self.last_timestamp
            # L104: It must also be <= max_sample_gap (0.5 s). not makes the branch run when either bound fails.
            <= self.config.max_sample_gap
        # L105: Finish the multiline gap condition. A gap exactly 0.5 s is accepted.
        ):
            # L106: Disallowed gap: reset phase and candidate, preserving rep_count. Then continue with this packet.
            self.reset_phase()
        # L107: Remember this packet's generation for the next comparison.
        self.generation = packet.generation
        # L108: Remember its selected person ID.
        self.track_id = packet.selected_track_id
        # L109: Remember its timestamp, including when its pose is missing or invalid.
        self.last_timestamp = packet.timestamp
        # L110: Remember its frame index so duplicate/older work can be ignored next time.
        self.last_frame = packet.frame_index
        # L111: Check whether the selected person was observed in this packet.
        if not packet.present:
            # L112: If absent, forget the partial cycle and candidate.
            self.reset_phase()
            # L113: Stop this packet without classifying its missing pose. Preserve the current total after any reseeding.
            return self.rep_count
        # L114: Get the current-frame label from classify(). Note that classify() itself may reset phase on invalidity.
        posture = self.classify(packet.pose)
        # L115: None means either invalidity or a valid intermediate pose. Both cases have no new candidate to confirm.
        if posture is None:
            # L116: Cancel the candidate timer's active posture. The old start time is irrelevant while pending is None.
            self.pending = None
            # L117: Stop with no increment. In a valid intermediate pose self.state has stayed unchanged.
            return self.rep_count
        # L118: If this posture differs from the current candidate (including no candidate), start a new matching run.
        if posture != self.pending:
            # L119: Tuple assignment stores both the new candidate and THIS packet's timestamp as its start.
            self.pending, self.pending_since = posture, packet.timestamp
        # L120: If observed elapsed candidate time is still less than 0.06 s, it is too brief to confirm.
        if packet.timestamp - self.pending_since < self.config.confirm_seconds:
            # L121: Wait for another qualifying packet; keep the existing stable phase and repetition total.
            return self.rep_count
        # L122: The candidate is now confirmed. Handle the special unarmed UNKNOWN phase first.
        if self.state == ExerciseState.UNKNOWN:
            # L123: Only confirmed CLOSED can arm UNKNOWN. Confirmed OPEN is intentionally ignored in this branch.
            if posture == ExerciseState.CLOSED:
                # L124: Arm the cycle by remembering CLOSED. This does not increase the count.
                self.state = ExerciseState.CLOSED
        # L125: Otherwise, if already armed, react only when the confirmed posture differs from the stable phase.
        elif posture != self.state:
            # L126: The counting edge: the previous stable phase must be OPEN and the new confirmed posture must be CLOSED.
            if self.state == ExerciseState.OPEN and posture == ExerciseState.CLOSED:
                # L127: Add exactly one completed repetition. This is the only increment in the file.
                self.rep_count += 1
            # L128: Remember the new confirmed posture for either CLOSED -> OPEN or OPEN -> CLOSED.
            self.state = posture
        # L129: Return the total. Repeating the same posture produces no edge and therefore no extra count.
        return self.rep_count

What stops or resets a cycle?

What arrives?Stable phaseRepetition count
Duplicate / older frame numberLeave everything unchanged; ignore the packet.Unchanged.
Different selected ID or continuity generationReset to UNKNOWN, then process this packet.Replace the worker's count with packet.accepted_reps.
Same continuity, sample gap outside [0, 0.5 s]Reset to UNKNOWN, then process this packet.Preserve total.
Selected person absent; bad required joint; invalid width or spanReset to UNKNOWN; clear pending.Preserve total after any identity reseeding.
Valid intermediate postureKeep the stable phase; clear pending.Preserve total.

A generation is the main controller's continuity marker. It changes on selection, loss and recovery, even if the tracker ID is unchanged. After a reset the person must establish CLOSED again before another full cycle can count.

reset_phase() does not zero the count. It changes only the stable phase and pending candidate. Identity/generation changes separately reseed the count from the main process's accepted total.
